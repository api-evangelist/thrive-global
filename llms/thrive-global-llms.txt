# Thrive Global

> Thrive Global is a behavior-change technology company founded by Arianna Huffington that helps employers and healthcare organizations improve wellbeing through Microsteps across five daily behaviors: Connection, Food, Movement, Sleep, and Stress Management. Its Partner API serves the Thrive content library (Resets, stories, microsteps, challenges, courses, podcasts, meditations, and programs), and an official MCP server exposes user wellbeing data and actions to AI assistants.

Generated by API Evangelist from the provider's published surface (no /llms.txt is published by Thrive Global; developers.thriveglobal.com serves its SPA shell for that path).

## MCP

- [Thrive MCP server](https://mcp.thriveglobal.com/mcp): official remote MCP server (Streamable HTTP, SSE fallback), OAuth 2.0/OIDC via Keycloak, client ID thrive-mcp-server; 9 tools covering wellbeing status, daily tasks, intention, content recommendations, microstep check-ins, and content search
- [MCP documentation](https://developers.thriveglobal.com/mcp)

## Authentication

- Exchange your partner API key (x-api-key header) for a 12-hour JWT bearer token via POST /v1/auth with a unique userId; use Authorization: Bearer on all content endpoints
- [Authentication guide](https://developers.thriveglobal.com/authentication)
